# 创作台 UI 改版验证

日期：2026-10-28。本轮在客户端和 Host 模块拆分、生成可靠性修复之后调整界面，参考[即梦官方首页](https://jimeng.jianying.com/ai-tool/home/)的输入区、参数条、作品浏览和详情层次。

## 本轮变化

- 统一暗色背景、文字层次、间距、圆角、SVG 图标和浅薄荷色圆形发送键。页头保留品牌、连接状态和渠道设置，图片 / 视频切换统一到输入卡的创作类型菜单。
- 输入区保留参考图、首尾帧、提示词、参数和快捷键；模型名称缩短展示，菜单说明、悬浮提示和详情保留完整模型 ID 及渠道，提交仍使用渠道与模型的联合标识。
- 作品使用原始宽高比的多列瀑布；状态区分处理中、待核实、未提交、失败和已完成，媒体加载失败另有提示。视频悬停播放和作品操作保留，键盘聚焦及触屏可访问卡片操作。
- 详情左侧完整展示媒体，右侧分组展示提示词、模型、参数与任务信息。正文独立滚动，保存、复用和恢复等操作固定在底部；恢复查询后的任务状态会实时同步到已打开的详情。
- 按插件面板实际宽度适配 1–4 列，避免 DSH 侧栏或分栏占用空间后仍套用宽屏布局。窄屏详情上下排列，菜单横向限制在面板范围内。
- 菜单支持方向键、Escape 和焦点返回；详情与渠道设置支持焦点循环、Escape 关闭及返回打开位置。减少动态效果的系统偏好被保留。

生成快照、提交去重、恢复与重新生成、渠道设置、下载结果反馈仍走现有模块。没有新增运行时依赖；DSH 继续加载单个构建后的 `client.js`，使用宿主提供的 React。

组件与流程回归覆盖上传、参数、图片 / 视频切换、菜单键盘操作、详情焦点循环与关闭、渠道设置、任务恢复及重新生成、多产物和部分下载失败。新增验证确保打开详情时恢复未知任务不会额外生成，并能显示后续任务状态。

## 真实 DSH 检查

本机已有的目录安装显示新版页头、单一模式入口、参数条及三列作品。原有 **5 条作品**仍可读取；切换视频后可见首尾帧、Seedance 模型、时长和声音参数，再切回图片正常。打开旧作品详情，可见完整图片、参数、费用、缺少完整输入的提示和固定的保存 / 复用区，Escape 可关闭。

本轮未点击真实生成、保存渠道配置或删除作品；真实 DSH 检查只证明界面加载与这些交互可用。未知 / 失败等异常状态和生成回归来自隔离预览及模拟上游测试，不代表真实 Provider 的生成验收。此轮也不覆盖即梦画布、素材库、收藏分组及其专有生成能力。

## 本地复看

```sh
npm run preview
```

打开控制台输出的 loopback 地址即可；加 `?empty=1` 看空状态，`?embed=1` 隐藏模拟侧栏，`?compact=1` 看窄面板。结束时按 Ctrl+C。模拟素材和预览服务不进入插件运行包。
