# 模块化第三步验证记录

验证日期：2026-10-28（Asia/Shanghai）。

## 页面结构

| 文件/目录 | 职责 |
| --- | --- |
| `src/client/plugin.js` | DSH 注册及 Host、存储、翻译和 React 的依赖装配 |
| `src/client/app/Studio.js` | 页面整体状态、生成/轮询/保存及各功能模块装配 |
| `src/client/features/composer/Composer.js` | 创作输入、图片上传、模型参数及生成操作 |
| `src/client/features/gallery/` | Gallery、Tile 与 Lightbox；作品操作通过回调交给 Studio |
| `src/client/features/channels/SettingsDialog.js` | 渠道配置表单与模型探测 |
| `src/client/ui/` | 菜单和侧栏图标 |
| `src/client/styles/studio.js` | 原 CSS 字符串，随客户端一起打包 |
| `src/client/i18n.js` | 每个插件实例独立的字典和翻译绑定 |

组件工厂在初始化时创建一次，接收 DSH 提供的 React；渲染期间不重新创建组件类型。翻译使用稳定的代理函数，在 DSH 绑定语言后仍读取当前翻译。整体状态和定时器仍归 Studio，基础业务模块沿用第二步的实现。

## 工程与行为验证

环境：Node.js v22.22.3、npm 11.14.1。新增的 React 19.3.1、ReactDOM 19.3.1、jsdom 30.1.3 均为锁定版本的开发依赖；运行产物仍使用 DSH 的 React。

- `npm ci`、`npm run build`、`npm run verify` 和 `git diff --check` 通过。
- 共 35 项测试通过，本批新增 7 项真实 React/DOM 及翻译测试。
- 模拟 DOM 不加载远端资源，测试生成/模型探测使用模拟回调，未调用真实生成渠道。
- 菜单选择、重新渲染时的状态保留及窗口事件监听清理通过。
- 图片上传、2 MiB 限制、比例参数和 Ctrl+Enter 操作通过。
- 作品列表、预览、保存/复用/删除回调中的作品标识保持一致。
- 渠道探测与保存回调通过；表单中的已有密钥保持为空，沿用 Host 的保留语义。
- 历史任务加载、轮询完成后更新作品、延迟保存，以及卸载时轮询/保存定时器清理通过。
- 页面切换保留输入组件身份，视频参数及生成请求、预览开关通过。
- 不同插件实例的字典和翻译绑定相互独立。

迁移时保留了 6 个原组件函数体。另用真实 React 渲染 Git 基线 `0ae5fab` 与本次构建产物，对照图片页、视频页、渠道弹窗和作品预览四种 DOM 状态，结果一致；CSS 字符串也一致。此对照检查不包含浏览器实际布局测量。

安装包检查仍生成并解包真实 `.tgz`，包含 10 个运行文件，Host 与 DSH 客户端入口可加载；运行包没有新增 npm runtime dependencies。

## 真实 DSH 检查

在现有本地目录安装中停用并重新启用插件，侧栏入口可移除并恢复。最终产物加载后检查：

- 图片页显示已连接、参考图、模型、比例、清晰度、张数及已有 5 条作品。
- 比例菜单可打开；点击视频导航后菜单关闭，页面切换为首帧/尾帧、时长和声音参数。
- 已有作品可打开预览，显示画面及任务信息，关闭后返回作品列表。
- 渠道设置可打开，显示两个已有渠道，关闭后回到页面；没有保存或更改配置。

没有提交真实生成任务、保存渠道配置或删除作品。实际 DSH 检查覆盖加载和上述交互，自动化测试中的生成、探测和轮询使用模拟环境。
