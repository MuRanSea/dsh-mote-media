## 本次实现

- 随插件提供并注册 `mote-image` 技能，支持模型自动发现和用户从聊天输入框主动选择。技能先查询实际模型目录，根据用途完善提示词及选择支持的比例、尺寸、分辨率、张数；保留用户硬要求及逐字画面文字。只要求方案或提示词时不生成。
- `mote_image` 复用创作台的持久化提交机制，保存原始要求、实际提示词、渠道、模型和参数。同一会话的同一工具调用重放复用提交标识；不根据变化后的默认配置重新选模型。未知结果不再次发起生成。
- `mote_media_task` 增加 `submission_id`，恢复原渠道查询并按原保存偏好处理结果，保留旧 `task_id` 调用。图片生成完成默认保存，失败可以只重试下载，已保存文件优先用于预览。
- 客户端仅接管 `mote_image` 和 `mote_media_task` 的工具视图，解析实际结果正文；显示多张图片、模型、参数及两种提示词，支持大图预览、查询、保存和打开已保存文件。渲染卡片不会触发生成，视频和被替换的结果使用通用文本回退。
- 创作台同步聊天作品；逐张删除不会因后续轮询重建，删除一条提交的全部作品会保存隐藏标识。隐藏记录和轻量作品记录保存在浏览器，完整输入及收据留在 Host。

## 2026-10-29：组图语义纠正与图片展示修复（组图方案已被下节替代）

重新读取了实际渠道的 [mote 图片生成文档](https://platform.sgt.site/docs/media-images.md)，并核对 [Seedream 原生接口文档](https://www.volcengine.com/docs/82379/1541523?lang=zh) 及其本地官方快照。

- mote `/media/v1/images/generations` 的 Seedream `n>1` 表示关联组图，`n` 是最多输出几张，实际可能更少。参考图数加 `n` 不能超过 15，5 Pro 只支持单图。火山原生接口使用 `sequential_image_generation=auto` 和 `sequential_image_generation_options.max_images`；不能把两种接口字段混用。
- 原界面用通用“张数”描述 Seedream 组图，原技能也把多图需求直接归为数量参数，没有区分关联组图和独立出图。现将 mote Seedream 控件改为“单图 / 组图·最多 N 张”，按目录显示至多 15 个选项，并提示实际数量可能少于上限。OpenAI 兼容驱动仍按其数量参数展示。
- 工具参数说明及技能已区分两种意图：关联组图描述各图内容与关系；独立图片分别提交 `n=1` 任务。组图不足上限时报告实际产物，不自动补任务。本轮没有新增面板批量独立生成入口。
- 另复现了用户已有成功任务的展示问题：图片本身能够加载，但原图片卡处于默认折叠且有高度上限的工具活动组内。客户端新增 `conversation.chat.turnTail` 贡献，订阅本轮包括隐藏节点在内的工具结果，将图片显示到回复下方，按提交标识取最新结果去重，并处理嵌套调用及结果正文替换。
