# 创作流程与作品筛选验证

日期：2026-10-28。范围：再次编辑、图片 / 视频独立草稿、素材复用校验，以及作品搜索筛选。继续使用既有 Host 输入快照、提交去重和任务恢复接口。

## 用户可见行为

- 卡片与详情新增「再次编辑」，只读取快照并恢复编辑器。提示词、原渠道和模型、参数、参考图名称与角色、首尾帧均恢复。只有用户点击生成或生成快捷键后，才以新提交标识创建任务；原来的「重新生成」仍可直接使用完整快照。
- 图片与视频在同一次打开创作台期间分别保留草稿。切换模式保留提示词、模型、参数、参考图及首尾帧；离开页面或刷新后不保留这些内存草稿，不向浏览器作品记录写入大体积参考素材。
- 旧作品只恢复实际保存的内容，持续提示素材缺失。快照读取失败时保留当前草稿；原模型 / 渠道不存在或无法唯一确定时，不自动改用其他渠道，必须明确选择模型。
- 不支持的参考类型、角色或无可编辑 URL 的素材列出后阻止生成，可逐项移除；模型切换后不兼容的素材保留并提示。视频不能作为图片参考，模型数量上限生效；复用图片依次填充空的首帧 / 尾帧，再按能力加入普通参考，不覆盖已占用的帧。
- 本地上传检查图片 MIME、单文件 2 MiB 和组合素材大小。文件读取期间切换模式仍写入原模式；若原草稿已被作品恢复替换，旧上传不混入新草稿。快照读取期间用户已编辑、切换模式或离开页面时，旧响应不会覆盖后续输入。
- 搜索支持提示词、原始 / 展示模型名和渠道 ID，可与图片 / 视频及任务状态组合。状态区分处理中、待核实、尚未提交、完成、失败与取消。显示结果数量，提供无匹配提示和重置筛选。
- 筛选仅作用于显示，原记录与轮询继续保留。清理按钮只处理当前可见的已结束作品，不删除隐藏结果或待核实 / 处理中记录。

## 模块

- `src/client/domain/drafts.js`：快照与旧记录转换、参考素材兼容性及放入空位规则。
- `src/client/features/composer/useDrafts.js`：图片 / 视频草稿、初始模型选择、恢复版本与异步上传隔离。
- `src/client/app/Studio.js`：只读快照获取、恢复到编辑器、显式生成及现有任务协调。
- `src/client/features/gallery/`：作品筛选、再次编辑入口与带原因的复用禁用状态。

Host 协议、工具和运行依赖未增加，客户端仍构建为单个 `client.js`。
