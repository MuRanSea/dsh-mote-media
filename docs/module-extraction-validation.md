# 模块化第二步验证记录

验证日期：2026-10-28（Asia/Shanghai）。

## 模块职责

| 模块 | Interface 与职责 |
| --- | --- |
| `src/client/api/host-client.js` | `createHostClient()` 返回 `call`，集中处理 Host 请求、地址回退、错误和可用地址缓存；每个插件实例单独创建 |
| `src/client/domain/model-capabilities.js` | 模型选择、默认值、参数过滤、比例与像素转换、图片参考角色和数量；内部参数枚举实现不向页面暴露 |
| `src/client/domain/works.js` | 作品 ID、任务状态、产物选择和诊断导出；翻译函数作为参数传入 |
| `src/client/storage/works-storage.js` | `createWorksStorage()` 返回读取与保存操作，集中处理存储格式及异常 |

基础模块不依赖 React。通信与存储模块延迟访问浏览器，通过依赖替换直接测试；`plugin.js` 保留组件、React 状态、文件读取、轮询与保存定时器。

## 兼容要求

- 继续使用 `/api/mote-media`、现有 action 请求格式及 `credentials: same-origin`。
- 可用地址缓存仍属于单个插件实例，地址回退和错误传播维持现有行为。
- 继续使用 `mote-media.studio.v1`，保存前 120 条，维持顺序及存储失败时的回退行为。
- 模型参数过滤顺序、`false`/`0` 的保留、参考角色限制和预览产物选择维持现有规则。
- 继续构建为一个 `client.js`，运行包无需新增源码文件或运行时依赖。
