# Host 模块化验证记录

验证日期：2026-10-28（Asia/Shanghai）。

## 模块职责

| 文件/目录 | 职责 |
| --- | --- |
| `index.js` | DSH 入口；确定配置路径、创建媒体实例并注册工具与路由 |
| `mote.js` | 保留原有 12 个导出及媒体实例的 16 个方法 |
| `src/host/config/` | 配置规范化、覆盖文件、profile 写回和密钥保留 |
| `src/host/routes/` | 面板 action、产物访问、Connection 延迟注册和卸载清理 |
| `src/host/tools/` | 原有四个智能体工具的定义及执行入口 |
| `src/host/media/` | 媒体流程装配、模型目录、任务、产物、参考素材及输出格式 |
| `src/host/channels/` | 渠道注册与选择、HTTP 请求、mote/OpenAI 图片适配 |

每次插件 apply 只创建一个媒体实例，路由和工具共用该实例。模型缓存和 OpenAI 本地任务表分别创建一次，由目录、配置和任务模块共享。配置修改清空模型缓存，保留已有本地任务表。

覆盖文件位置由根入口的 `import.meta.url` 确定，显式传给配置模块；继续使用包根目录的 `.mote-state.json`。配置模块返回数据与状态，HTTP 序列化由路由负责，原有响应状态和字段保持兼容。
